# ASAR Assets

Asset publik untuk aplikasi ASAR (Asistensi ARKAS).

## Files

- `rekening_laporan.json` — pemetaan kategori dan kode rekening laporan.
- `npsn_whitelist.json` — daftar NPSN SD Kecamatan Rejoso yang diizinkan, sudah ditandatangani dengan kunci privat pengembang.

URL yang dipakai aplikasi:

```
https://raw.githubusercontent.com/dearpotsky/asar-assets/main/rekening_laporan.json
https://raw.githubusercontent.com/dearpotsky/asar-assets/main/npsn_whitelist.json
```

Perbarui file di branch `main` lalu tombol sinkronisasi di menu **Pembaruan** akan mengambil versi terbaru.
